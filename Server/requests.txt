1. CREATE INTERNSHIP ASSIGNMENT (ASSIGN INTERN TO MENTOR & DEPARTMENT)
================================================================================
POST http://localhost:3000/api/v1/mentors/internships
Content-Type: application/json
Authorization: Bearer YOUR_ADMIN_TOKEN

Body (raw):
{
  "intern_id": "69db67c510beece3a928a4c3",
  "mentor_id": "69da4ef18c7722705d3fa15e",
  "department_id": "69da2a9c3d67a977f330f31a",
  "subject": "Backend API Development",
  "start_date": "2026-04-13",
  "end_date": "2026-06-13",
  "status": "active"
}

IMPORTANT - Status Handling:
- If you DON'T provide 'status', it will be AUTO-CALCULATED based on dates:
  * If start_date is in the FUTURE → status: "pending"
  * If start_date is TODAY or PAST, and end_date is in FUTURE → status: "active"
  * If end_date is in the PAST → status: "completed"
  
- If you DO provide 'status' (optional), it will use the value you set
- Valid status values: "pending", "active", "completed"

Example without status (auto-calculated):
{
  "intern_id": "69db67c510beece3a928a4c3",
  "mentor_id": "69da4ef18c7722705d3fa15e",
  "department_id": "69da2a9c3d67a977f330f31a",
  "subject": "Backend API Development",
  "start_date": "2026-06-01",
  "end_date": "2026-08-01"
}
Result: status will be "pending" (start_date is in future)

Expected Response (201):
{
  "msg": "Internship assignment created successfully",
  "assignment": {
    "_id": "newAssignmentId",
    "intern_id": {
      "_id": "69db67c510beece3a928a4c3",
      "full_name": "Ahmed Ali",
      "email": "ahmed@university.com",
      "university_id": "2023001"
    },
    "mentor_id": {
